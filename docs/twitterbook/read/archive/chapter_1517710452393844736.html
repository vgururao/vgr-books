I increasingly find it more useful into “middle class” in terms of work than standard of living

Lower class = below the API
Middle class = lower half of above-API work
Upper class = top half of above API work

Most useful agency is now middle class

Upper class has only one mode of weakening agency: investing

Lower class is trapped in gamified mazes they can’t escape that take up all their time/attention/energy

Middle class has all the inflation resistant skill capital

Your NPV is higher and you’ll have no trouble deploying your knowledge capital easily.
