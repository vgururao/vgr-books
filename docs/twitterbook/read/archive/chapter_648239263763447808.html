A false sense of security, when punctured, turns into a false sense of crisis. The bipolar disorder of finite-game Utopianism/dystopianism.
🔗
To figure out if a sense of crisis is well-founded, first check if the sense of security it disrupts is well-founded.
🔗
By this heuristic, the "illegal immigrant crisis" is false, because it disrupts a false sense of American middle class economic security.
🔗
Now trying to refine the test and apply it to more things. Key is to define a true sense of security, which is surprisingly hard.
